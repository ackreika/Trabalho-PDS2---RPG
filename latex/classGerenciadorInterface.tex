\doxysubsection{Detailed Description}
Conhece em qual tela de menu o jogador está e guarda as configurações de áudio/vídeo (\doxylink{classGerenciadorInterface}{Gerenciador\+Interface}, no CRC). 

A aplicação real do volume/resolução no motor (Audio\+Server, Display\+Server) é feita pelo Godot; aqui só fica o DADO da configuração.

Estado\+Menu, do lado do GDScript, é só um número (int) — a correspondência é\+: 0 = MENU\+\_\+\+INICIAL, 1 = MENU\+\_\+\+JOGAR, 2 = MENU\+\_\+\+CONFIGURACOES, 3 = MENU\+\_\+\+INVENTARIO, 4 = EM\+\_\+\+BATALHA
