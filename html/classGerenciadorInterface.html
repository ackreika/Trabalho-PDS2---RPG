Detailed Description

Conhece em qual tela de menu o jogador está e guarda as configurações de áudio/vídeo (GerenciadorInterface, no CRC).

A aplicação real do volume/resolução no motor (AudioServer, DisplayServer) é feita pelo Godot; aqui só fica o DADO da configuração.

EstadoMenu, do lado do GDScript, é só um número (int) — a correspondência é: 0 = MENU_INICIAL, 1 = MENU_JOGAR, 2 = MENU_CONFIGURACOES, 3 = MENU_INVENTARIO, 4 = EM_BATALHA
