Detailed Description

Orquestra a progressão da run (GerenciadorSemestre, no CRC): sabe em qual área o jogador está, em qual das 4 batalhas daquela área, e quando a run inteira foi vencida ("Fuga do ICEx").

idArea: 0=Cálculo, 1=Física, 2=GAAL, 3=PDS (nessa ordem fixa)
