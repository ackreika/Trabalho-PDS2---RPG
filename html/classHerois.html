Detailed Description

Representa o Estudante (jogador) durante uma run.

Guarda status (vida, defesa, dano), os 3 movimentos escolhidos pelo jogador, os itens passivos coletados na run atual, o item especial equipado (4º slot de golpe na batalha) e o item de história usado contra bosses invulneráveis.
